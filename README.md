# 🎬 FilmyCosmo Movies

**FilmyCosmo** is a fast, modern movie discovery and streaming web application. It provides users with instant access to a vast collection of movies and web series across various genres and categories including Bollywood, Hollywood, South Dubbed, Dual Audio, and 4K/HD releases.

## 🌟 Overview

FilmyCosmo offers a sleek dark-themed interface designed for smooth browsing, real-time search, detailed movie information, quality download links, and personalized watchlists.

### Key Features
- **Movie Catalog**: Explore latest releases, trending films, and popular web series.
- **Category & Genre Filtering**: Filter movies by Bollywood, Hollywood, South Dubbed, Web Series, or genres.
- **Fast Search**: Instant search across titles, cast, genres, and quality options.
- **Movie Details & Downloads**: View screenshots, star cast, ratings, synopsis, and active download links (480p, 720p, 1080p, 4K).
- **My Watchlist**: Save your favorite movies to your personal list for quick access.

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
